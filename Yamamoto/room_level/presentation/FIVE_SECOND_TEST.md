# 5秒テスト(発表スライドが「一目で分かる」か確かめる)

## 手順
1. 発表を知らない人に、スライドを**5秒だけ**見せる(スライドショーで表示し、5秒で閉じる)。
2. 閉じたあと、聞く。
   - 「何が書いてありましたか。1文で言ってください」
   - 「一番目立ったものは何でしたか」
3. 下の表の「言えてほしいこと」と比べて、○(言えた)/△(一部)/×(言えない)を付ける。
4. 3人以上にやる(研究室、ゼミの友達、できれば専門外の人も1人)。
5. 最後に「意味の分からなかった言葉」を聞く。

## 判定
- **×が2人以上のページ**は、情報が多すぎる。文字か図を減らす。
- **△が多いページ**は、タイトルか強調が弱い。
- 専門外の人が言えなかった言葉は、最初に1回、絵で説明する(AUCなど)。
