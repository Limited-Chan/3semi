# AIに分析してもらうためのガイド

まず `90_ai_ready_all_factors.csv` をAIに読み込ませてください。
必要なら観点別CSVも追加してください。

主なファイル:
- 00_overview.csv: 国分寺市全体
- 01_station.csv: 最寄駅別
- 02_walk.csv: 駅徒歩別
- 03_layout.csv: 間取り別
- 04_rent.csv: 家賃帯別
- 05_area.csv: 面積別
- 06_building_age.csv: 築年数別
- 07_price_per_sqm.csv: 1㎡あたり家賃別
- 08_start_month.csv: 掲載開始月別
- 09_start_year.csv: 掲載開始年別
- 11_station_x_walk.csv: 最寄駅×駅徒歩
- 12_layout_x_rent.csv: 間取り×家賃帯

AIへの依頼例:

このデータは東京都国分寺市の賃貸物件について、掲載開始から掲載終了までの期間を条件別に集計したものです。
件数、掲載期間中央値、7日以内終了率、14日以内終了率、30日以内終了率を中心に分析してください。

1. 掲載終了の早さに違いがありそうな観点
2. 傾向が弱い・判断できない観点
3. 件数が少なく注意すべき条件
4. 追加でクロス集計すべき組み合わせ
5. 問い合わせ優先度の候補として使えそうな変数

単なる差を因果関係とは断定しないでください。
また、掲載終了は成約とは限りません。
家賃と間取り、駅徒歩と最寄駅などの交絡にも注意してください。
