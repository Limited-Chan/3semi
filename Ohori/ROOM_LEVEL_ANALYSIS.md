# 部屋単位の監査と、似た物件の中での順位付け(08〜11)

ChatGPTが作った原案を、実データで動かして直したもの。既存の `01〜07` と `src/` の他のファイルは変更していない。

## 何をするか

| ファイル | 内容 |
|---|---|
| `src/listing_episodes.py` | 建物ID＋住戸IDで同じ部屋の重複・連続掲載を統合する。矛盾の判定は、つなごうとしている掲載どうしだけで行う。最寄駅の違いは記録のみで統合は止めない |
| `analysis/08_unit_audit.py` | IDの有無、統合できた件数、統合できなかった理由(間取り・面積の食い違い)を出す。統合ルール0/1/7/14日の感度つき |
| `analysis/09_candidate_ranking.py` | 同時に掲載中の似た物件(間取り×築年数10年帯×家賃2万円帯)の中で、7方式の順位付けを比べる。グループ単位のブートストラップで95%区間を出す。`--gap N` で統合ルールを選ぶ |
| `analysis/09b_segment_sensitivity.py` | 候補集合の「似かた」を5通りに変えて、属性が順位付けに足す情報を測る(探索的) |
| `analysis/11_two_level_priority.py` | 優先度の境界(2022年の重み付き3分位点)を決め、2023年に固定して実終了率を出す。報告書の35.71% / 51.66%と17.2・17.3節の表を再現する |
| `tests/test_listing_episodes.py` | 統合ロジックの単体テスト(5件) |

`summary_tables/` に、2026-10-12に実行した結果の要約表を入れている(生成物の`results/`はgitignoreされている)。

## 実行順(Ohoriフォルダから)

```
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p test_listing_episodes.py -v
python -m analysis.08_unit_audit
python -m analysis.09_candidate_ranking --gap 1
python -m analysis.09b_segment_sensitivity
# 11は 04, 06, 07 を先に実行しておく
python -m analysis.11_two_level_priority
```

入力は、リポジトリ直下の `data/prepared/kokubunji_raw.parquet`(`src/data.py` の `SOURCE_COLUMNS` で国分寺市を抽出したもの)。

## 結果の要点(2020〜2023年・国分寺市)

- 全掲載にIDがある。統合すると、2020〜2023年の掲載は22,332件から15,276件になる(ルール1日)。間取りや面積が食い違う779組(6,415掲載)は統合していない。
- **似た物件の中の順位付けは、どの方法もAUC約0.53〜0.55。** Model 2は、掲載経過日数だけを使う方法と差がない(差−0.004、95%区間は−0.038〜+0.016)。統合ルールを変えても同じ。
- 候補の種類が違うほど属性が効く。間取りだけが同じなら+0.026、条件なしなら+0.044(`09b`)。
- 報告書の15〜17節の数字(Brier、AUC、境界値、優先度ごとの実終了率)は、すべて再現できた。

## 注意

1. `building_id`＋`unit_id`が同じでも、実際に同じ部屋とは断定していない。間取りの食い違いが603組あり、IDが部屋を一意に表さない場合がある。
2. 統合ルール(重なる掲載、1日以内の連続)は仮定で、0/1/7/14日の感度を見る。
3. 掲載終了は成約ではない。
4. 2023年の結果を見たあとの追加分析なので、独立した未使用のテストではない。
5. `09`の学習は、2023-01-01より前に分かる掲載終了情報だけを使う。報告書の数値と一致しない場合がある。
6. 大きい候補集合(`09b`)は、同じ物件が複数の日に出るため区間を出していない。
7. `11`の「高/低」は、予測リスクを中央値で分けたもの。掲載期間の長短で分ける方式とは別物。

# 追加分析(12〜28番)

すべて「探索的」。2023年のデータは何度も見ているため、独立した未使用のテストではない(2024年1〜3月は26番で初めて使った)。結果の表は `summary_tables/`(番号つき)。実行時の出力は `results/`(git管理外)。

## 最終的な結論(7日・2段階。28番まで)

12〜19番は、報告書の方式(30日・3段階)をたどり直す分析だった。最終的な方式は、**7日以内に終わる確率が15%以上=高、未満=低の2段階**で、20番以降でその根拠と限界を確かめた。要点は次のとおり(近隣10市+国分寺市、探索的)。

- 2023年: 高15.4%、低7.9%で**1.95倍**(95%区間 1.81〜2.09)。でたらめに分けると差は0(25番)。
- 未使用の2024年1〜3月: 高25.3%、低15.7%で**1.61倍**(1.48〜1.74)。傾向は再現した(26番)。
- ただし、15%の境界は2024年1〜3月に合わない(高が58%に増える)。最も似た物件の中では差が消える(−0.2pt)。築年数だけの目安(+9.9pt)がモデル(+9.6pt)と同程度。
- 1つの条件だけの目安より差が大きい(2023年 +7.5ptに対し+3.4〜+5.0pt)。3条件の集計(+6.6pt)とは誤差の範囲内(25番)。
- 3段階と2段階は、境界を同じ方法で決めると、3段階のAUCが約0.01〜0.02高い。差は小さく、目的(急ぐか決める二択)に合う2段階を採用(27、28番)。
- 測っているのは「掲載終了」で、成約や問い合わせではない(契約日の記録は22,332件中14件)。問い合わせ優先度は、現状のデータでは確かめられない。

## 結果の要点

- **高/低の出し方(12, 14。報告書方式の30日・3段階の結果で、最終方式ではない)**: 予測リスクを分ける方式は、掲載期間の長短で学習する方式より、似た候補の中で優れる。部屋単位・7日以内の予測で、2022年で決めた境界(8.0%/13.4%)を2023年に固定すると、実終了率は低5.4%/中10.5%/高16.2%。
- **学習する地域の範囲(15)**: 国分寺市だけ、近隣10市、多摩全体でも、似た候補の中のAUCは±0.01以内。データを増やしても精度は上がらない。
- **使う情報を増やす(17)**: 近隣10市+国分寺市、30日、最も厳しい候補集合(間取り×築年数×家賃)。Model 2のAUCは0.547。
  - 部屋の履歴(過去365日): −0.005、建物の空室数: +0.002、近くの掲載数: −0.003。いずれも改善なし。
  - 勾配ブースティング(HGB)に替えると+0.020(0.567)、さらに履歴・建物・需給を足すと+0.024(0.571)。
  - 現況・入居可能時期を足すと+0.041(HGBとの併用で+0.072)。ただしこれは主に「居住中」「期日指定」を見分けているだけで、人気ではなく掲載の都合を表す可能性が高い。
  - 履歴・需給は、取り込み期間(2020年開始以降)による不公平を避けるため、窓を過去365日に固定し、学習は2021〜2022年開始だけにしている。
- **較正(18)**: 2021〜2022年開始で学習したModel 2を2023年に当てると、予測確率が高く出すぎる(7日: 予測平均14.5%、実際10.2%。最上位10%は予測26%に対し実際17%)。順位は保たれる。確率の%をそのまま見せるのは避け、高/低のラベルで示す方がよい。
- **境界の固定(19)**: 2021年開始で学習し2022年で決めた境界(7日: 予測15%以上=高)を、2023年にそのまま当てた。高は全体の30%で、実終了率は高15.4%/低7.9%(差7.5pt)。同じ間取りの候補どうしでは+6.2pt(95%区間+4.8〜+7.8)、間取り・築年数・家賃まで同じ候補では+3.4pt(+1.8〜+5.1)。
- **「差はほとんどない」の表示(18)**: 点数の幅が小さい集合で高低をつけない規則は、該当する集合が少なく、実際の差を取り出せなかった。検証済みの主張にはしない。


## 20〜28番の結果の要点

- **境界の選び方(20)**: 同じ間取りの2件を比べたときの効き目は、10〜12%で最大、15%を超えると下がり、20%はかなり悪い(2022年10%、2023年12%で最大)。12%と15%の直接比較は、2022年だけ有意(+0.61)で、2023年は有意でない(+0.18、−0.20〜+0.51)。15%は妥当な選択だが、最適とは言えない。
- **発表用の数字(21)**: 22,332件、7,357部屋、統合後15,276件。契約日の入っている掲載14件。掲載日数の中央値22日、平均50.17日。Kaplan–Meier法の終了割合は、7日29.7%、14日41.5%、22日50.7%、30日57.9%、90日85%。欠損率は築年数3.8%、面積0.1%、間取り0.4%。順位相関は築年数+0.311、家賃−0.228、面積−0.123、距離−0.016。相関比は間取り0.16、最寄駅0.04、開始月約0.10。
- **予測期間(22)**: 似た候補の中のAUCは、7/14/30日でほぼ同じ(近隣10市+国分寺市 0.545/0.540/0.547)。上位30%を高としたときの高/低の倍率は、7日1.95倍、14日1.89倍、30日1.59倍。7日は最良だからではなく、短くて使いやすいから選んだ。
- **図(23a〜i)**: 高・低の比較、確率の補正、境界の選び方、情報追加、AUCの比較、部屋の件数、時間とともに終わる割合、家賃・間取り・開始月の中央値。入力は `summary_tables/` の表だけ(再学習しない)。
- **同じ条件の掲載日数(24)**: 間取り×築年数帯×家賃帯ごとの掲載日数(100件以上、Kaplan–Meier法)。「高・低に加えて事実も見せる」提案の数字。
- **誤差範囲と簡単な目安との比較(25)**: 2023年の候補33,672件で、高/低の倍率は1.95倍(1.81〜2.09)。差(pt)は、モデル+7.5、掲載日数だけ+3.4、家賃帯だけ+5.0、間取りだけ+4.0、築年数帯だけ+4.7、3条件+6.6(モデルとの差−0.87、−1.63〜+0.04)、でたらめ−0.2。高の割合はどれも約30%にそろえ、目安は2022年の候補から作る。区間は部屋単位の抽出し直し(1000回)。
- **未使用の2024年1〜3月(26)**: 学習は2021〜2022年開始、モデル・7日・15%は動かさない。5つの日付(1/15、2/1、2/15、3/1、3/15)の候補15,400件(部屋5,971)。高25.3%、低15.7%、1.61倍(1.48〜1.74)。高の割合58%。予測平均17.8%に対し実際21.3%(2023年とは逆向き)。モデル+9.6pt、築年数だけ+9.9pt(差+0.35、−0.80〜+1.67)、3条件+8.9pt。間取りだけ同じ候補では+10.2pt、最も似た候補では−0.2pt(−3.7〜+3.3)。国分寺市だけは1,023件で、+2.1pt(−6.0〜+13.3)となり判断できない。候補は掲載開始から90日以内のものだけで、2023年と経過日数の分布が違う。
- **3段階と2段階(27、参考)**: 2段階は目的から決めた15%、3段階は別の決め方(A: 2022年の3分位、B: 10%・15%、C: 15%・25%)で、境界の決め方が揃っていない。全体のAUCは、2023年が2段階0.586、3段階A 0.611、B 0.608、C 0.589。2024年1〜3月が2段階0.570、3段階A 0.568、B 0.578、C 0.577。
- **3段階と2段階の公平な比較(28、結論に使う)**: 2段階・3段階とも、同じ方法で2022年だけで境界を決め、動かさず適用。V1は等分(2段階10.3%、3段階7.9%と13.3%)、V2は2022年のAUC最大(2段階11.7%、3段階8.5%と14.0%、各グループは全体の10%以上)。3段階−2段階の全体のAUCの差は、V1が2023年+0.027(0.020〜0.032)、2024年+0.019(0.011〜0.026)、V2が+0.022(0.015〜0.029)、+0.013(0.007〜0.020)。どちらでも3段階がわずかに高い。2024年は境界が合わず、V2の2段階は高が74%、3段階は低が8%・高が63%。グループ数より、境界の安定性が課題。

## 注意

- `building_id` が 1 / 3 は仮のIDで、多摩の掲載の15%を占める。履歴・建物の特徴量では「ID不明」として扱った。もともと統合ルールでブロックされ、統合されていなかったため、14番までの数字への影響は小さい。
- 掲載終了は成約ではない。「高」の物件でも約85%は7日以内に終わらない(相対的な分け方であって、当てるものではない)。
- 境界(15%)は目的から決めた値で、2022年の結果で妥当性を確認した。未使用の2024年1〜3月(26番)では通用しなかった(高が58%に増える)。23区や2024年4月以降での確認はまだ。
- 国分寺市だけで見ると候補集合が少なく、区間が広い。
- HGBは反復の上限(300回)まで使っており、調整していない。
