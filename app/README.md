# すぐ埋まる？ナビ

国分寺市の賃貸物件の**掲載終了リスク**を研究データから分かりやすく見る大学ゼミ発表用アプリ。

## 起動（Windows / PowerShell）

リポジトリのルート（`3semi` フォルダ）で実行します。

```powershell
git pull origin main
cd app
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload
```

ブラウザで `http://127.0.0.1:8000/` を開きます。更新後は `Ctrl + Shift + R` でキャッシュを無視して再読み込みしてください。

## 画面・使い方

1. **研究データ**（`/#/`）：`app/historical.csv` の**全40条件**を表示。間取り・築年数帯・家賃帯・高低・キーワードで検索、4通りの並べ替え、詳細表示が可能。
2. **詳細**（`/#/group/ID`）：条件別の過去件数、掲載12日目から7日以内の掲載終了割合、25%・50%・75%が掲載終了した日数、お問い合わせを検討する上での参考コメントを表示。
3. **キープ・比較**（`/#/saved`）：保存した条件の終了割合・件数・中央値を横並びで比較。保存状態はブラウザ内に保持。
4. **物件を分析**（`/#/analyze`）：気になる物件の条件を手入力し、研究の学習済みモデルが使用可能なら7日以内の個別予測、なければ同条件の過去実績を表示。モデル推論でエラーが起きても過去実績は表示し、サーバーログにエラーを記録する。

**架空の物件11件を使った旧デモ画面は削除しました。** 物件一覧と誤認されないよう40件は「40条件の集計グループ」として表示します。

## データと研究上の注意

- `app/historical.csv` は `Yamamoto/room_level/summary_tables/24_same_condition_duration.csv` をもとにした条件別集計です。各行は実在する個別物件ではなく、間取り・築年数帯・家賃帯による複数の賃貸掲載記録の集計です。
- 7日以内の掲載終了割合は、**既に12日掲載されていた場合の、その後7日以内の過去割合**です。どの掲載日数にでも当てはまる個別予測確率ではありません。
- 15%を境界とする高・低は研究発表の区分であり、契約・問い合わせ成果・空室状況を予測するものではありません。
- `Ohori` の保存済み学習モデルは別の分析手順によるもので、条件別過去集計とは統計的な意味が異なります。2つを混同せず、表示を区別しています。
- 元の巨大な賃貸TSVや個別物件レコードは不要です。公開リポジトリにアップロードする必要はありません。

## 学習済みモデル

`final_model2_age_layout.joblib` を自分で学習・保存している場合にのみ、以下のいずれかに設置します。

- `app/models/final_model2_age_layout.joblib`
- `Ohori/results/07_final_test/final_model2_age_layout.joblib`

このファイルが**ない場合**は過去実績のみを表示します。joblibは任意のPythonオブジェクトを実行できる形式のため、信頼できる自作ファイルだけをロードしてください。

モデル保存時と実行時のscikit-learnバージョンを一致させます。現在のアプリは `scikit-learn==1.9.1` を指定しています。

`http://127.0.0.1:8000/api/status` でバージョンとモデルの配置先を確認できます。実際の推論で失敗した場合は端末に `Property analysis model inference error` のスタックトレースが出ます。

## API

- `GET /api/groups`：全40集計条件
- `GET /api/historical`：条件別の掲載終了実績
- `POST /api/analyze`：入力した物件条件のモデル推論（または過去集計）
- `GET /api/status`：モデルの状態
- `GET /docs`：APIドキュメント

画像・架空の11件・現在の賃貸情報を捏造した表示はありません。
