# 築年数・間取り分析レポート

本レポートは `analysis_kokubunji/` 配下の集計済みCSV(帯別・カテゴリ別の件数と掲載期間統計量)を用いて作成した。物件1件ごとの生データ(bukken_rent TSV)は容量の都合でリポジトリに含まれていないため、ヒストグラムのビン幅は既存の帯区分に従い、散布図・相関係数は帯/カテゴリ単位の近似値である。

## 築年数
グループ化統計量(近似): 平均19.8年 / 中央値18.5年 / 最頻値(推定)3.9年 / 標準偏差13.1年

- 築11〜20年: 件数6,147 / 平均34.1日 / 中央値12.0日 (平均 > 中央値(右に歪み))
- 築31〜40年: 件数5,286 / 平均86.0日 / 中央値39.0日 (平均 > 中央値(右に歪み))
- 築21〜30年: 件数5,039 / 平均88.5日 / 中央値34.0日 (平均 > 中央値(右に歪み))
- 築5年以下: 件数4,043 / 平均32.0日 / 中央値13.0日 (平均 > 中央値(右に歪み))
- 築6〜10年: 件数2,863 / 平均24.3日 / 中央値11.0日 (平均 > 中央値(右に歪み))
- 築41年以上: 件数903 / 平均103.6日 / 中央値42.0日 (平均 > 中央値(右に歪み))

築年数帯ごとの掲載期間は、どの帯も平均が中央値を上回っており、右に裾を引く分布(長期掲載の少数の物件に平均が引っ張られる形)になっていると考えられる。そのため代表値としては外れ値の影響を受けにくい**中央値**が妥当。

築年数自体の分布も、平均(19.8年)が中央値(18.5年)よりやや大きく、右に緩やかに裾を引く形になっている。単純な件数最多の帯は「築11〜20年」だが、帯の幅(10年)を考慮した度数密度でみると最も密度が高いのは「築5年以下」の帯であり、最頻値は約3.9年と推定される。したがって築年数の代表値も、件数最多の帯だけで判断せず中央値・最頻値をあわせて確認するのが妥当。

間取りはカテゴリ変数であるため、間取りそのものの代表値は平均・中央値ではなく**最頻値(最も件数の多いカテゴリ)**で示すべき。掲載期間については、間取りごとに平均が中央値より高い傾向が共通しており、こちらも中央値を代表値として使うのが妥当。

## 生データがない場合の限界
- ヒストグラムのビン幅を1年/5年刻みで検討する、という計画書の手順はlisting単位の生データが必要であり、集計済みデータのみでは実行できない。既存の帯区分(不均等幅)をそのまま用いた。
- 相関係数は帯/カテゴリの代表値(平均・中央値)同士から計算した参考値であり、listing単位のピアソン/スピアマン相関とは異なる(自由度がbin数しかないため解釈には注意が必要)。
- 生データ(bukken_rent_v1.0.1.tsv)を用意できる場合は、listing単位の再分析を推奨する。
