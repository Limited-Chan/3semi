# Step 1: distribution inspection

Analysis scope: **22,332 listing records**.

Numeric bins are equal-width across the complete observed range. No overflow category is used.
Each variable has one complete CSV; PNGs are split into fixed numbers of adjacent bins only for readability.

The exact steps, full finite edges, and page sizes are saved in `00_scope/band_schema.json`.
The program does not choose mean/median/mode automatically.
